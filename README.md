# Crypto Portfolio (Local Edition)

Простой и мощный инструмент для мониторинга криптовалютного портфеля, работающий полностью в вашем браузере. Все данные хранятся локально и никуда не передаются.

## 🚀 Основные возможности

- **Отслеживание сделок**: Фиксация цены покупки, количества, инвестиций и профита.
- **Интеграция с Bybit API**: Автоматическое получение актуальных цен для монет в вашем списке.
- **Watchlist (Список наблюдения)**: Отслеживание уровней интереса и целей по монетам.
- **Локальное хранение**: Все данные сохраняются в `localStorage` вашего браузера.
- **Экспорт/Импорт**: Возможность выгрузить все данные в JSON-файл для резервного копирования или переноса на другое устройство.
- **ROI и Статистика**: Автоматический расчет доходности портфеля и отдельных сделок.
- **Интегрированная навигация**: Единая панель переключения между портфелем, тепловой картой доходности и историей BTC.

---

## 🛠 Как запустить

Приложение не требует установки дополнительных зависимостей или серверов.

1. Откройте файл `trade_local.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).
2. Для автоматического обновления цен убедитесь, что у вас есть доступ к интернету (для запросов к API Bybit).

---

## 🔒 Безопасность и конфиденциальность

- **100% Приватность**: Приложение не использует базу данных на сервере. Ваши сделки видите только вы.
- **Без API-ключей**: Для работы не требуются секретные ключи от бирж (используется только публичное API для получения котировок).
- **Открытый код**: Вы можете просмотреть весь исходный код прямо в HTML-файле.

---

## ⚠️ Важные замечания

- **Очистка кэша**: Если вы очистите данные сайтов или кэш браузера, данные `localStorage` могут быть удалены. 
- **Резервное копирование**: Рекомендуется регулярно нажимать кнопку **"Экспортировать данные"** и сохранять JSON-файл.

---

## Структура файлов

- `trade_local.html` — основной файл приложения (интерфейс портфеля).
- `course/trade_cours.html` — тепловая карта ежемесячной доходности BTC (Returns).
- `course/trade_price.html` — история цен закрытия BTC по месяцам (История BTC).
