# Crypto Trade Tools

Набор инструментов для отслеживания крипто-портфеля и анализа исторических данных BTC.

## Основные возможности

- **Crypto Portfolio (trade_local.html)**:
    - Отслеживание портфеля в реальном времени.
    - Интеграция с API Bybit и Binance для получения актуальных цен.
    - Локальное хранение данных в браузере (localStorage).
    - Функции импорта и экспорта данных в формате JSON.
    - Список наблюдения (Watchlist) и статистика депозита.

- **BTC Monthly Returns (trade_cours.html)**:
    - Тепловая карта ежемесячной доходности BTC.
    - Автоматическая загрузка исторических данных с Binance.

- **BTC Monthly Closing Price (trade_price.html)**:
    - Таблица цен закрытия BTC по месяцам.

## Безопасность и конфиденциальность

- **Никаких личных данных**: Проект не собирает и не хранит ваши персональные данные, API-ключи или адреса кошельков на внешних серверах.
- **Локальное хранение**: Все данные вашего портфеля хранятся исключительно в вашем браузере (`localStorage`).
- **Open Source**: Код полностью открыт и работает на стороне клиента (Client-side).

## Как пользоваться

Просто откройте любой из `.html` файлов в вашем браузере. Для полноценной работы портфеля рекомендуется использовать `trade_local.html`.
